Star Ocean 5 - Windows 10/11 x64 - Experimental version 1.0.1
==========================================================

Start Star Ocean 5 Launcher.exe at the root of the extracted player folder.
The real launcher, game runtime, updater, extractor and DLLs are in bin.
Keep the complete folder together and use a writable location.

No PS4 game data or firmware is included. Supply your own supported decrypted
Star Ocean 5 PS4 game directory or supported PKG. CUSA03219 is the tested edition;
other recognized PS4 editions are marked untested. A supported x64 CPU and
Vulkan 1.3 graphics driver are required. Players do not need Python, MSYS2,
PowerShell or .NET. Optional DLSS requires its bridge/runtime and a compatible GPU.

Use Game to select/prepare data and manage saves. Use Video for the target monitor,
GPU, supported output size, reconstruction and internal scene resolution.
Manual internal resolution is available with reconstruction off; FSR/DLSS presets
own the input size when enabled. Scene resolution does not replace UI textures.
Native ultrawide scene rendering is separate from final fitting and HUD placement.
Prerendered video retains its original aspect ratio.

Open the in-game Cockpit with Insert or L2 + right-stick click (R3).
Cheats are native and title/version checked. Tweaks includes exploration leader
switching, camera following and HUD JSON layout selection. O/P or D-pad left/right
cycle the leader when enabled. F2 or R2+L2 holds acceleration when enabled.
Anisotropic filtering, input mappings and interface language require a new session.

Saves use the active user/title save directory. Automatic backups use the same
runtime backup engine at launch and supported backup save requests. Close the game
before replacing active saves; close the launcher before replacing protected backups.
Never share your game files, saves, settings or diagnostic captures as application files.

Console output remains English and can be selected/copied or exported. Performance
capture is optional and disabled by default. Enable its tools in Advanced, then arm
Capture next session in Logs and diagnostics. Enabling tools alone does not record.

Known issue: FSR 4 v07 may show an outdoor/zone-transition bottom-edge line and reduced
smoothing. No correction is included in this source update. Reconstruction off avoids
the reported line but provides less temporal smoothing. Subtitle layout, title-screen
globe and brief 16:9 transition composition still have limitations. Frame generation
is not implemented. Full-playthrough and broader hardware validation remain necessary.

See README.md, CHANGELOG.md, docs/LAUNCHER_GUIDE.md and docs/IN_GAME_MENU_GUIDE.md.
