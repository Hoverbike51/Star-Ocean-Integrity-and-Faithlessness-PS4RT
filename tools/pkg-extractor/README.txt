ShadPS4Plus PKG Extractor 1.1
================================

Upstream: https://github.com/AzaharPlus/shadPS4Plus
Release: PKG_EXTRACTOR_1_1 (21 January 2026)
License: GPL-2.0; see the PS4RT package root LICENSE file.

This unmodified upstream command-line extractor is invoked through
PS4RT-PkgExtractor.exe. Its first argument is the PS4 PKG path and its second
argument is the destination directory. The launcher always extracts into an
isolated directory below the current Windows user's LocalAppData folder.

  zlib1.dll          F2C31972BD69E1B2CA759E95E847A57213B4459978E25D5F6CD989A743B55D20

Only extract packages you are legally entitled to use. The helper runs without
administrator rights and does not download keys or bypass operating-system
security controls.
